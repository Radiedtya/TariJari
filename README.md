🎵 TariJari — Game Ritme Saku
fokus, cepat, dan menyenangkan.

TariJari adalah game ritme (rhythm game) kasual berbasis web yang menantang pemainnya untuk menekan nada yang jatuh di empat jalur berwarna neon. Dengan kontrol sederhana, bangun kombo tanpa henti, raih skor sempurna, dan selesaikan 9 level dengan intensitas yang terus meningkat — semua dibungkus dalam estetika arcade malam hari yang memukau.

🎮 Cara Bermain
Permainan menggunakan 4 jalur yang masing-masing terhubung dengan satu tombol:

🟥 Jalur Merah -> Tekan D
🟨 Jalur Kuning -> Tekan F
🟩 Jalur Hijau -> Tekan J
🟦 Jalur Cyan -> Tekan K(Atau langsung tap jalurnya jika bermain di layar sentuh)
Saat nada menyentuh garis tekan di bagian bawah, tekan tombol yang sesuai. Ketepatan waktu menentukan hasilnya:

✨ Sempurna: +100 poin
👍 Bagus: +50 poin
❌ Meleset: Kehilangan 1 nyawa
Setiap tekanan benar menaikkan combo (semakin tinggi kombo, semakin besar bonus poin). Kamu hanya memiliki 3 nyawa. Melewatkan 3 nada berarti permainan berakhir!

✨ Fitur Utama
9 Level Bertahap: Mulai dari tempo lambat 80 BPM hingga intens 155 BPM dengan pola nada yang unik.
Sistem Progresi: Selesaikan level untuk membuka level berikutnya dan kumpulkan bintang.
Tanpa Hambatan: Tidak ada proses pendaftaran, tidak perlu unduh aplikasi besar. Buka browser, langsung main.
Dukungan Lintas Perangkat: Bisa dimainkan menggunakan Keyboard (PC/Laptop) maupun Tap Layar (HP/Tablet).
Aksesibilitas: Tersedia tombol untuk mematikan suara atau mengurangi efek gerakan (Reduced Motion).
Audio Dinamis: Efek suara dihasilkan secara real-time mengikuti irama beat menggunakan Web Audio API.
🛠️ Teknologi yang Digunakan
React + TypeScript: Antarmuka pengguna yang dinamis dan terstruktur.
Tailwind CSS v4: Desain antarmuka yang responsif menggunakan plugin @tailwindcss/vite terbaru.
HTML5 Canvas: Merender permainan yang halus dan cepat (60 FPS).
Web Audio API: Menghasilkan suara ketukan dan musik langsung dari browser tanpa file MP3 eksternal.
